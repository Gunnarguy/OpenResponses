NAME
OpenResponses

SUBTITLE
Responses API & Voice Tools

PROMOTIONAL TEXT
Try GPT-6 Sol, Astra and Luna and GPT Image 2.5 in a native Responses API playground with voice, MCP tools, browser automation and a raw-request Workbench.

DESCRIPTION
OpenResponses is a native iPhone and iPad playground for the OpenAI Responses API. Bring your own API key, control your requests, inspect tool activity and explore current models in SwiftUI.

CHAT WITH CONTROL
• Choose GPT-6 Sol, Astra or Luna, the GPT-5.6 family or earlier supported models. Newer general-purpose releases in your account's model list are recognized automatically.
• Adjust compatible reasoning, context, verbosity, image and tool settings.
• Stream replies, inspect API-provided reasoning summaries, follow token usage and review request/response details.
• Save prompt presets, attach photos and documents, export conversations and keep local history.

API WORKBENCH
• Edit JSON requests using HTTP, streaming or WebSocket transports, with secure draft recovery and local schema validation.
• Inspect raw events and export complete final response payloads.
• Count input tokens, compact context, retrieve, cancel or delete responses, and manage conversations, files, vector stores, containers and batches.
• Call models, moderation, embeddings and Realtime client-secret endpoints directly, with confirmation before any delete.
• Explore templates for hosted shell, tool search, custom tools, async/programmatic calling, multi-agent responses and images. Supply real client tool results when a request needs them.

VOICE, IMAGES AND TOOLS
• Have continuing voice conversations with GPT Realtime 2.1 or GPT-Live 1, with microphone mute and interruption handling.
• Generate and edit images with GPT Image 2.5 Flare or Sunburst, up to Max quality, with partial previews.
• Use hosted web search with sources, Code Interpreter and file search when enabled.
• Navigate and interact with an on-device WebKit browser using page tools or Computer Use. Cancellation, deadlines and action limits help keep runs controlled; some sites and authentication flows require manual interaction.
• Connect supported apps through provider sign-in, select several accounts per chat and inspect MCP tools. Search 44 catalog entries or the public registry; provider setup requirements are labeled.
• Enable Calendar, Reminders, Contacts or Notion tools for the tasks that need them.

FILES, BATCH AND CONTROLS
• Manage files and vector stores with clear indexing status.
• Monitor Batch jobs and save full available output/error files.
• Add response moderation, hybrid file-search ranking, larger Code Interpreter containers and image fidelity controls.

YOUR KEY, VISIBLE DATA FLOW
• Explore Demo Mode without sending live API requests.
• Store API credentials in the iOS Keychain and review the first-live-send data-sharing notice.
• No separate OpenResponses account is required. OpenAI usage is billed to your own API account.

Requires iOS 17 or later. Live features need an OpenAI API key with appropriate billing and model/tool access; third-party tools may need their own accounts and permissions. Feature availability and service limits vary. AI output can be inaccurate; verify important information before acting.

WHAT'S NEW
OpenResponses 2.7 adds OpenAI's newest models and prepares the app for the releases that follow.

NEW MODELS
• GPT-6 Sol, the new default for new presets, alongside GPT-6 Astra and GPT-6 Luna, with every reasoning level each model supports, from None to Max.
• GPT Image 2.5 Flare and Sunburst, with the new X-High and Max quality settings and partial previews. GPT Image 2 remains available.
• Later general-purpose GPT releases that appear in your account's model list are recognized automatically, with current reasoning and tool controls.

STAYING CURRENT AS OLDER MODELS RETIRE
• Voice sessions saved with a Realtime model OpenAI is retiring switch to GPT Realtime 2.1.
• The offline model list leaves out models with announced shutdowns. Your account's live model list and the model ID field reach every current model your API project can use.
• Image quality adjusts automatically when you switch to an image model that does not accept the chosen setting.

CURRENT API COVERAGE
• GPT-Live 1 voice sessions through OpenAI's new Live API, selectable in Settings → Model → Voice. GPT Realtime 2.1 remains the default.
• Response moderation, live-web-access control for web search, hybrid file-search ranking, Code Interpreter memory limits, image input fidelity and compression, and the Fast and Ultrafast service tiers.
• The API Workbench now reaches every current endpoint the app works with: responses, conversations, models, moderation, embeddings, files, vector stores, containers, batches and Realtime client secrets. Deletions ask first.
• Batch jobs default to the Responses endpoint.
• Voice notes recorded with the microphone button are transcribed with GPT Transcribe into the message field, so you can edit them before sending.

REMOVED BECAUSE OPENAI SHUT THEM DOWN OR DEPRECATED THEM
• Assistants API tools and the Assistant import lab, fine-tuning jobs, published prompts, preview web search and preview computer-use tools, and retired models such as o1, o3, o4-mini and GPT-5. Saved chats keep working, and presets that used a retired model switch to OpenAI's recommended replacement, such as o3 to GPT-5.6 Sol.

RELIABILITY
• MCP tool discovery uses GPT-6 Luna, the lowest-cost current model.
• Concurrency and memory-handling fixes in the API Workbench, conversation saving and voice recording.
• The Computer Use notice now explains that approval is requested when OpenAI flags a safety check.
