# OpenAI API gaps, November 2026

Gap report between OpenAI's API as documented on developers.openai.com and what OpenResponses 3.0 (build 56, commit `2b361da`) does.

- Every OpenAI page below was read through the openai-docs MCP server on 2026-11-19 between 22:28 and 22:40 Pacific (2026-11-20 UTC). "Read 2026-11-19" in this file means that window.
- App behavior comes from grep over `OpenResponses/` (Swift sources) and `OpenResponses/Resources/ModelCatalog/ModelCatalog.json`, plus README.md, CHANGELOG.md (3.0 to 2.7), docs/api-refresh-2026-09.md and docs/ai/codemap/INDEX.md. "grep X: 0" means `grep -rn --include='*.swift' -F 'X' OpenResponses` returned no lines. Nothing was built or run.
- The streaming events reference is 2.3 MB. Its event list was extracted from the `## event` headings; the per-event schemas were not read.

## Deprecations and shutdowns that affect the app

From https://developers.openai.com/api/docs/deprecations, read 2026-11-19.

- **Dec 11, 2026:** `gpt-5`, `gpt-5-mini`, `gpt-5-nano`, `gpt-5-pro`, `o3`, `o3-pro`. The app already retires them; its replacements differ from the page (see the table).
- **Jan 11, 2027:** GPT-5.2, GPT-5.4 and GPT-5.4 mini with EU data residency and `service_tier: fast` or `priority`. Relevant only to EU projects; the tier picker does not warn.
- **Jan 14, 2027:** `gpt-4o-2024-08-06`, `gpt-4o-2024-11-20`, `gpt-4o-mini-2024-07-18`, `gpt-4.1-2025-04-14`, `gpt-4.1-mini-2025-04-14`; replacement `gpt-6-luna`. All four base IDs are in the catalog's `earlier` list (ModelCatalog.json:16).
- **Jan 20, 2027:** `gpt-realtime`, `gpt-realtime-mini`, `gpt-4o-realtime`, `gpt-4o-mini-realtime`; replacements `gpt-realtime-2.1` and `gpt-realtime-2.1-mini`. Already handled (CurrentModelCatalog.swift:20-23).
- **Feb 10, 2027:** `gpt-image-2` and `gpt-image-2-2026-04-21`; replacement `gpt-image-2.6-sunburst` or `gpt-image-2.6-flare` (notice Nov 10, 2026). The app still offers `gpt-image-2` (CurrentModelCatalog.swift:18).
- **Feb 26, 2027:** `whisper-1`, `gpt-4o-transcribe`, `gpt-4o-mini-transcribe`, `gpt-4o-transcribe-diarize`, `/v1/audio/translations`. The app uses `gpt-transcribe` and `gpt-live-transcribe` (CurrentModelCatalog.swift:24-27). No action.

## Contradictions between doc pages

Recorded as found, not resolved.

1. **Ultrafast models.** The Responses create reference (search index text for https://developers.openai.com/api/reference/resources/responses/methods/create) says Ultrafast "is currently available for gpt-5.6-sol". The Ultrafast guide lists GPT-6.2 Astra, GPT-6.2 Sol, GPT-6 Astra and GPT-6.1 Sol, and does not list GPT-5.6 Sol.
2. **`prompt_cache_retention`.** The create reference marks it "Deprecated. Use prompt_cache_options.ttl instead." The caching guide's model table says GPT-5.5 and earlier models use `prompt_cache_retention` (`"24h"` only for GPT-5.5; `"in_memory"` or `"24h"` for older ones), and the GPT-6.2 migration guide says to replace it with `prompt_cache_options.ttl` only "when migrating from GPT-5.5 or earlier". The app removed `prompt_cache_retention` in 2.7 as deprecated, so earlier-generation models in its `earlier` list have no lifetime control.
3. **GPT Image 2.6 in the Responses tool.** The GPT-Image-2.5 Flare page says to select it "as the model of the Responses API image generation tool". The GPT-Image-2.6 Flare page lists endpoints `image_generation, image_edit` only, the changelog entry lists only `v1/images/generations` and `v1/images/edits`, and the image guide describes the 2.6 features "through the Image API". The deprecations page still names 2.6 as the replacement for `gpt-image-2`, which the app uses in the Responses tool. Whether 2.6 works in the Responses `image_generation` tool is not stated.
4. **Data residency table lags.** Its `/v1/live/sessions` row lists only `gpt-live-1`, not `gpt-live-1.1`; its `/v1/images/*` rows list no GPT-Image-2.6 model.
5. **Shut-down endpoints still listed.** The OpenAPI endpoint list from the docs server includes `/assistants`, `/threads` and `/videos`; the deprecations page says the Assistants API shut down Aug 26, 2026 and the Videos API Sep 24, 2026. The web search guide's usage-notes table still lists Assistants under API availability.
6. **Prompt objects.** The create reference still documents `prompt` ("Reference to a prompt template and its variables") while `/v1/prompts` shuts down Nov 30, 2026.
7. **Cache retention default.** The May 29 changelog entry says `prompt_cache_retention` "now defaults to `24h`" for non-ZDR organizations without naming models; the caching guide says GPT-5.6 and later default to `"30m"` through `prompt_cache_options.ttl`.
8. **Live standby.** The Nov 19 changelog offers standby for "GPT-Live-1 and GPT-Live-1.1 WebRTC sessions". The app connects over WebSocket (RealtimeService.swift:127), so standby does not apply unless the app adds WebRTC.

Not resolved: the create reference describes a "Request level image options" field and an `access_programs` field (also present in the reference's example responses) whose parameter names and schemas were not read.

## Already covered

Confirmed in the sources named, so nobody re-researches them:

- Responses create, retrieve, cancel, delete, input items, input token counting, standalone compaction, automatic compaction through `context_management` (OpenAIService.swift:2111-2113) (docs/api-refresh-2026-09.md, CHANGELOG 2.7).
- Conversations: create, retrieve, items with pagination, update, extend, delete in the Workbench (docs/api-refresh-2026-09.md, CHANGELOG 2.7).
- Transports: HTTP, SSE and persistent Responses WebSocket; mid-turn steering with `response.steer`; reasoning change mid-conversation with `configuration_update` in the Workbench (docs/api-refresh-2026-09.md).
- Reasoning: model-aware effort, summary, context (`auto`, `current_turn`, `all_turns`), pro mode, encrypted reasoning replay for stateless turns; `none` mapped to `low` where rejected (CHANGELOG 2.8).
- Tools: function, custom text tools, async tool calling, programmatic tool calling, multi-agent beta over WebSocket with `response.inject`, tool search with `defer_loading` (OpenAIService.swift:1088-1093), hosted shell `container_auto`, apply patch in the Workbench, Code Interpreter with `memory_limit`, File Search with `ranking_options.hybrid_search`, web search with `external_web_access`, `allowed_domains`, sources, user location, MCP with Keychain credentials, approvals and OAuth, Computer Use through the app's own browser (CHANGELOG 2.7, 2.9; README).
- Streaming events handled: `response.function_call_arguments.delta`/`.done`, `response.custom_tool_call_input.delta`/`.done`, MCP call and list-tools events, image partials, web, file and Code Interpreter in-progress events, `response.output_item.added`/`.done`, annotations (ChatViewModel+Streaming.swift:28-84; CHANGELOG 3.0, 2.9).
- Image generation: GPT Image 2.5 Flare and Sunburst with `xhigh` and `max` quality, transparency with png or webp, `input_fidelity`, `output_compression`, up to three partial previews (CHANGELOG 2.7; docs/api-refresh-2026-09.md).
- Service tiers `fast` and `ultrafast` exist in the picker (CHANGELOG 2.7); per-model gating is the gap above.
- Moderation object on Responses requests (CHANGELOG 2.7). `safety_identifier` and `prompt_cache_key` (SettingsHomeView.swift:634-640).
- Cached-token and cache-write-token reporting (ManagedResponsePresentation.swift:69-76).
- Voice: GPT-Realtime 2.1 and 2.1 mini, GPT-Live 1 over `/v1/live/sessions`, `gpt-live-transcribe` for input transcription, barge-in handling (CHANGELOG 2.7, 2.8; RealtimeService.swift).
- Voice notes with `gpt-transcribe` (OpenAIService.swift:4446-4464).
- Decisions API GA: `POST /v1/decisions` on gpt-6-luna, predicate, choice and score questions, up to 400 questions, one image input (CHANGELOG 3.0).
- Batch: Responses, Chat Completions, Embeddings, Moderations and Images endpoints, `completion_window` `24h` (the only value the Batch guide allows), output and error downloads (BatchJobsView.swift:23, BatchService.swift:50). Not covered: `output_expires_after` (grep: 0), a minor option.

- Removed after OpenAI shutdowns: Assistants, fine-tuning, prompt objects, `web_search_preview`, `computer_use_preview`, `user` (CHANGELOG 2.7).
- Not used by the app, so their deprecations need no work: `/v1/audio/speech` and the `tts-1` family (grep `audio/speech`: 0), `/v1/audio/translations` (grep: 0).
