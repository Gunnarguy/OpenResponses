3.0 puts every setting where you can find it, connects to a lot more apps, and shows you what the model is sending to a tool while it's still writing it.


SETTINGS

• Settings is one list of pages instead of five tabs, and each row shows what it's set to now, like the model and its reasoning effort or how many tools are on.

• Search finds about 50 options by name or by what they do, so typing "pyodide" takes you straight to Local Python.

• Local Python, the hosted shell, multi-agent, tool search, moderation, voice and the API Workbench each have their own page.  Before, they were all at the bottom of the Model tab under one heading.

• Text Size is new.  Leave it on Same as iPhone, or pick a size just for this app.

• At the biggest text sizes, Settings, tool steps, the welcome screens and the message field keep whole words now instead of splitting them up or cutting them off.


CONNECTORS

• Connected Apps is now Connectors.  It opens on the popular services, grouped by what they do, with the remote servers from the public MCP Registry listed under them, and search covers both as you type.

• Services that have to approve an app before you can sign in used to have no button at all.  Now you can try signing in, and if that's refused, connect with a key or token from that service's settings.

• GitHub's official server is in the list.

• Notion is a connector like the rest.  If you added a Notion integration token in an earlier version, it shows up there as its own connection.


TOOL STEPS

• When the model calls one of the app's own tools, like the browser, Calendar, Reminders, Contacts, Local Python or your Custom tool, its step fills in the arguments as the model writes them.  Before, the step stayed empty until the whole call had come in.  Tap the step to see them.


DECISIONS

• There's a new Decisions screen in Settings, under Developer, for OpenAI's Decisions API.  You write some text or add a photo, ask it yes or no, pick-one or score questions, and it gives you back how likely each answer is instead of a written reply.  It runs on GPT-6 Luna, and you only pay for the input, at $0.10 per million tokens.

• The API Workbench has a Create decision endpoint too, so you can send the raw request yourself.


CALENDAR AND REMINDERS

• Events and reminders get added when the model leaves the time zone off a time, which it does a lot.  In 2.9 those failed, twelve out of twelve on one photographed schedule.  Now a time with no zone is read in your phone's time zone.


ALSO

• Rating is Apple's own sheet, which can show up once per version after an answer finishes, and About has a Rate OpenResponses link that opens the App Store's review page.


Still no account, still your own key, and your chat history stays on your phone.
